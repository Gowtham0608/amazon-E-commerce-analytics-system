# E-Commerce Analytics & Business Intelligence Platform

## Project Overview

This project simulates an Amazon-style E-Commerce platform using MySQL.

The database manages customers, sellers, products, orders, and order items while providing business intelligence and analytics capabilities.

The project demonstrates database design, SQL querying, KPI tracking, sales analytics, and customer insights.

---

## Business Objectives

- Track customer purchases
- Monitor seller performance
- Analyze sales revenue
- Measure inventory levels
- Identify top customers
- Evaluate return rates
- Generate business KPIs

---

## Database Architecture

### Core Tables

| Table | Purpose |
|---------|---------|
| Customers | Customer information |
| Sellers | Marketplace sellers |
| Products | Product catalog |
| Orders | Customer orders |
| Order Items | Product-level transactions |
